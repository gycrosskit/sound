# 跨端行为候选

iOS 远端改用 AVPlayer/AVPlayerItem 原生网络预缓冲，避免同一合法 HTTPS 音效仅因超过库内完整下载的 2 MiB 上限而失败。删除完整 ByteArray/NSData 下载路径及其 Darwin/MockEngine 依赖；本地 Bundle fallback 仍使用 AVAudioPlayer。公开构造器和 SoundPlayer API 不变。

同一个 owner 维护 Main 串行入口、generation、5 秒准备 deadline、失败同址重试、未就绪回退和永久 RELEASED。准备期每 50ms 检查原生 item.status；READY 后每秒检查一次，补足尚未播放时没有 failed-to-end 通知的失败状态。原生播放失败/结束 notification 仍即时处理；换址/释放取消协程、seek、notification observers 和 player item。该单播放器轮询边界已在源码 ponytail 注释中说明；没有增加 KVO 桥或新的 wrapper。

定向 iOS 测试使用生产 IosSoundPlayer，覆盖HTTPS URL 直接传入原生 item、5 秒 deadline、旧 item notification、重复 play 后 release、后台排队，以及 PREPARING/REMOTE_FAILED 同步观察者 release 后不得创建播放器/回退资源。真实 >2 MiB HTTPS WAV 另用链接本次 framework 的最小 Simulator App 验证；Gradle standalone runner 的本地 WAV 准备失败证据保留，网络传输与扬声器验收单列。
