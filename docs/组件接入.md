# Sound 组件接入

本轮 Maven 目标版本 `0.1.2` 尚未发布；现有可用 Maven 版本为历史已验收的 `0.1.1`。本轮 HAR 未修改，继续安装 `@gycrosskit/sound@0.1.0`。发布进度以 [0.1.2 远程发布验收](0.1.2远程发布验收.md) 为准；完整依赖示例见 [README](../README.md#gradle-接入和版本)。

| 平台 | 组件与版本 | 调用线程与释放 |
| --- | --- | --- |
| Android | `sound-core:0.1.2` 候选 | 构造只保存 Application Context、状态和 Main Handler；`prepare` / `play` / `release` 可从普通后台或 Kuikly Renderer 调用，内部在 Main 串行执行。Main 调用立即执行；后台调用仅入队。`0.1.1` 仍需宿主在 Main 调用。 |
| iOS | `sound-core:0.1.2` 候选 | 入口在主线程调用；下载协程回到 Main 操作 AVAudioPlayer 与状态。Swift Framework 由宿主 export 对应版本；不提供独立 Swift Package。 |
| OHOS Kotlin | `sound-core:0.1.2`、`sound-kuikly:0.1.2` 候选 | `SoundModule` 在 Kuikly 页面线程串行调用，桥结果由 Kuikly 回到页面线程；`release` 撤销常驻 callback 后异步通知原生。 |
| OHOS ArkTS | `@gycrosskit/sound@0.1.0` | 在所属 ArkTS 执行上下文调用；Renderer 在原生侧拥有播放器，事件与 Promise 回调在该上下文执行。原生 `release` 返回本地资源串行释放 Promise，远端释放已发起。 |

宿主负责本地资源：Android `res/raw` ID、iOS Bundle 名称与扩展名、OHOS `resources/rawfile` 文件名；宿主声明网络权限并决定音频会话、业务触发、音效开关。共享 `SoundState` 仅描述准备及生命周期，StateFlow 观察方负责自己的 UI/Kuikly 线程切换。

页面或会话拥有单个播放器，离开时显式调用 `release()`。Android 后台 `release()` 返回不代表完成，应以 `state.phase == RELEASED` 确认 Main 已执行；Main 释放先于已排队操作时，旧操作不得重建播放器。Android 按 MediaPlayer 身份拒绝迟回调，iOS/OHOS 使用 generation；Kuikly Kotlin 撤销 callback。释放永久关闭实例，重新进入需创建新实例。状态回调并不承诺真机音频已播放成功，设备验收需使用宿主自己的格式与网络。
