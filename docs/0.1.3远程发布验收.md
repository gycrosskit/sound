# Sound 0.1.3 远程发布验收

2026-10-05，[PR #8](https://github.com/gycrosskit/sound/pull/8) 已合并，[不可变 Release 0.1.3](https://github.com/gycrosskit/sound/releases/tag/0.1.3) 已发布。标签提交 `1a03aae30fae2a94ef261330dd02e459d56c111f`；Maven 归档 SHA-256：`8c2f9706805be4b3f52d5c94549efd4b3c1ba32d3bb2a82e4451905a71b616c0`。Release 实际重下载字节一致，JitPack 最终 public/tag/commit 精确匹配。

## 修复与配套

iOS `prepare/play/release` 自动回到 Main：Main 同步执行，后台入队。释放调度独立于预载 scope，先停止/释放播放器、关闭 client 与 scope，再发布 RELEASED；排队入口及旧 generation 不得复活。后台调用 release 以 RELEASED 确认完成。Android 已有同类入口，本轮生产代码不变。OHOS 保留所属 Kuikly 页面线程合同；原生 HAR 源码与版本仍为 `@gycrosskit/sound@0.1.0`，没有伪造新 HAR 或重新上架声明。

## 本轮实际验证

- iOS Simulator 12 项测试、Android 8 项测试通过，failure/error/skipped 均为 0；iOS arm64/x64 编译通过。新增测试运行真实 IosSoundPlayer，覆盖后台排队、释放确认、scope 取消与释放后入队；不声称模拟真实扬声器或已完成网络请求。
- OHOS Node harness 转译并运行真实 SoundModule/SoundPlayer，检查 onDestroy、待创建播放器与迟 prepared 回调释放；只替代系统 SDK/资源，不代替 ArkUI 真机。
- 发布脚本 23 项测试、本轮完整 8-publication 构建、本地 metadata/POM/许可证、variant 文件及四种 hash/sidecar、归档校验通过。
- 远程 8 个 publication、8 个唯一 variant 文件逐项下载；大小、四种声明 hash、归档 CRC、内部精确依赖及 available-at 同名目标通过。16 个 MD5/SHA-1 制品 sidecar 匹配；16 个 SHA-256/SHA-512 sidecar HTTP 404，记录为 JitPack 渠道缺失，未计为通过。
- 干净工程仅从 HTTPS 远程仓库解析精确 `0.1.3`；禁止本地 Maven、flatDir、includeBuild 和外部工程依赖。Android 编译、iOS arm64/x64 编译、Simulator Framework 最终链接、OHOS core/Kuikly 编译通过，守卫记录全部 8 个精确组件坐标。依赖缓存使用 refresh；没有用 staging 或源码替换组件。

本轮不重复发布未改原生 HAR。真实音频格式/焦点/会话、网络超时及设备播放由宿主/用户验收；上述测试和编译不能证明设备业务通过。历史 0.1.2 记录保持原状。
