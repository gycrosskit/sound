# sound 功能与平台差异

适用版本：Maven 0.1.5；HAR 0.1.2。Maven 源码由不可变 Git 标签 `0.1.5` 定位；HAR 源码由 `har-0.1.2` 定位，本轮仅删除重复远端就绪状态，公开 API 不变。构建、checksum及各渠道实际验收结果见[版本发布记录](https://github.com/gycrosskit/sound/releases/tag/0.1.5)，源码/替身测试范围见本页验证表；不声明真实设备业务验收通过。

## 产物与职责

| 模块/产品 | 实际职责 |
|---|---|
| `sound-core` | SoundPlayer、SoundState/Phase、URL/准备规则；A MediaPlayer，i远端AVPlayer/本地AVAudioPlayer。 |
| `sound-kuikly` | 仅ohosArm64 SoundModule（GycSound），页面线程调用；Android/iOS直接使用core，不需此Module。 |
| `@gycrosskit/sound` | HAR SoundPlayer、SoundModule；OHOS AVPlayer+rawfile，compatibleAPI22/target26。无独立Swift Package。 |

构建边界：[core构建](../sound-core/build.gradle.kts)、[Kuikly构建](../sound-kuikly/build.gradle.kts)、[模块清单](../settings.gradle.kts)、[OHOS SDK配置](../ohos/build-profile.json5)。

除上表明确的 UI 入口外，本库没有独立 CMP 页面模块。Android/iOS 可由宿主原生适配把同一能力供 CMP 与 Kuikly 使用；“可注入两套UI”不代表库自动完成宿主接线、同名 Renderer 注册或品牌验收。

## 五入口功能矩阵

“原生实现，宿主注入”表示平台能力已有源码，CMP/Kuikly由宿主适配接入；“OHOS Module已实现”表示已有Kotlin/ArkTS调用链。矩阵说明功能接入边界，实际行为验证见下方验证范围。

| 功能/API组 | CMP Android | CMP iOS | Kuikly Android | Kuikly iOS | Kuikly OHOS |
|---|---|---|---|---|---|
| prepare / state / 5秒准备期限 | 原生实现，宿主注入 | 原生实现，宿主注入 | 原生实现，宿主注入 | 原生实现，宿主注入 | OHOS Module已实现 |
| 远端从头重播 / 本地回退 | 原生实现，宿主注入 | 原生实现，宿主注入 | 原生实现，宿主注入 | 原生实现，宿主注入 | OHOS Module已实现 |
| release / owner代次 / 重入保护 | 原生实现，宿主注入 | 原生实现，宿主注入 | 原生实现，宿主注入 | 原生实现，宿主注入 | OHOS Module已实现 |
| 音频资源/会话/业务开关 | 宿主注入raw ID | 宿主注入Bundle | 宿主注入raw ID | 宿主注入Bundle | 宿主注入rawfile |

## 公开 API 组

- `SoundPlayer.state` / `prepare(remoteUrl)` / `play()` / `release()`；SoundState.remoteUrl与SoundPhase是准备状态，不是播放进度。
- `normalizeSoundUrl`与`SoundState.nextPreparationState`提供共同URL/准备规则；平台播放器执行原生播放。
- OHOS `SoundModule(localResourceName)`实现SoundPlayer，`release`释放回调资格；原生SoundPlayer维护异步释放。

## API 合同与差异分类

| 分类 | 具体输入 / OS / SDK边界 | 调用方应如何处理 |
|---|---|---|
| 组件边界 | 空URL为LOCAL_ONLY；非空非法URL为REMOTE_FAILED；仅无凭据HTTPS，无内嵌空白。 | state表示准备与实例生命周期，不是正在播放/完整下载；同址PREPARING/READY不重复，失败同址可重试。 |
| 厂商限制 | A MediaPlayer、i AVPlayer、O AVPlayer预缓冲，准备5秒；不完整下载，不设库内文件字节上限。 | 候选iOS已移除完整下载2MiB模式；HTTPS重定向/TLS/编码支持由原生栈决定，宿主限制音频大小/时长及CDN链。 |
| 组件边界 | Android/iOS后台release先入Main；K RELEASED只确认桥关闭；O远端异步释放，本地release Promise收尾。 | 不能把调用返回/桥状态当全部底层网络释放完成；release永久关闭，重新使用需新实例。同步PREPARING/FAILED观察者撤销/替换后旧owner不创建播放器或回退。 |
| 宿主职责 | Android API24+ raw资源；iOS宿主建议14+（项目没有独立Swift Package最低版本声明，不能视为已验证更低版本），Bundle文件与全局AVAudioSession归宿主；OHOS兼容API22、目标API26。 | 静音键、后台播放、音频焦点及其它音频交互由系统和宿主会话决定；无混音/播放队列。 |
| 未验收 | 真实设备音频会话、静音键、后台音频、多品牌资源、API22设备兼容。 | 此前9MB HTTPS Simulator smoke是独立候选证据，不是本次真机或新远程制品验收。 |
