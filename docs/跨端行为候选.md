# 0.1.4 跨端行为候选（未发布）

iOS 增加 AVAudioPlayer delegate，监听 decodeError/didFinish(false)，与 Android/OHOS 一样转 REMOTE_FAILED，并在当前远端播放失败时回退宿主内置音效。delegate strong 引用随 remotePlayer 保留，释放时断开；旧 player/旧代次/释放后的回执不得影响新请求。StateFlow 同步观察者可在失败回执里 release，playLocal 重新检查 RELEASED 后才允许创建 fallback。

公开 IosSoundPlayer 构造器与 SoundPlayer API 保留。内部 HTTP/remote SDK 注入只用于定向测试，没有公共 wrapper。默认5秒准备 deadline/HTTPS准入/失败同址可重试/未就绪回退/永久释放不变；iOS 完整读取最多2 MiB，Android/OHOS原生流式预缓冲仍保留，REMOTE_READY不代表三端均完成完整下载。

验证：Android既有合同测试与OHOS编译通过；iOS common4+平台10=14项执行、零skip/failure。新增fixture执行真实生产状态机、StateFlow与delegate，真实临时NSBundle/wav；远端prepare/play/stop使用SDK替身，失败回执手动触发。已验证异步失败、旧回执隔离、同步release不创建fallback；未实际音频输出、设备解码故障或回退听感验收。

Maven 候选0.1.4；OHOS native源码未改，保持旧 HAR 版本配对。此前已发OHOS原生版本到当前生产源码只有注释差异，不能将打包tag跨度称为runtime drift；本轮真实差距在iOS delegate边界。未发布/未远程消费。
